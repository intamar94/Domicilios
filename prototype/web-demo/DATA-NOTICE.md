# Datos de terceros en el prototipo

## plz.json

Coordenadas del punto central de cada código postal alemán (lat, lng) y nombre de la localidad o barrio.

- **Coordenadas:** [WZBSocialScienceCenter/plz_geocoord](https://github.com/WZBSocialScienceCenter/plz_geocoord), Markus Konrad, Wissenschaftszentrum Berlin für Sozialforschung (2019). Licencia **Apache 2.0**. Redondeadas a 4 decimales.
- **Nombres:** paquete npm [german-metadata](https://www.npmjs.com/package/german-metadata) 2.0.1, licencia **MIT**.

Formato: `{"10115": [52.5326, 13.3777, "Berlin Mitte"], ...}` (8.298 códigos postales).
