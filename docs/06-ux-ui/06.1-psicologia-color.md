# 06.1 — Colores de FARO según la psicología del color

| Campo | Valor |
|---|---|
| Fase | 06 UX/UI |
| Estado | REVIEW |
| Criterio de aceptación | Paleta con función de cada color, justificación y contraste WCAG 2.2 AA comprobado |
| Evidencia | Este documento + aplicación en el prototipo web |

## 1. Conclusión

**Mantener la identidad del CLAUDE.md (azul profundo, teal y ámbar), cada color con un trabajo concreto:**

- **Azul profundo** da confianza.
- **Teal** es la marca y el color de «todo va bien».
- **Ámbar** es la calidez y el color de «haz esto ahora».

La combinación encaja con lo que una app de mandados entre vecinos necesita transmitir (confianza y cercanía) y no se confunde con los grandes servicios de reparto en Alemania.

**Lo que dice la ciencia:** el efecto de un color depende mucho del contexto. La teoría del color en contexto de Elliot y Maier sostiene que el significado de un color viene de experiencias y de la cultura, y que su efecto sobre el comportamiento cambia según la situación. Las revisiones señalan además que mucha investigación sobre color tiene poco rigor metodológico. Por eso esta paleta es una base razonable que **hay que probar con usuarios** (entrevistas de 01.7), no una verdad científica.

## 2. Qué transmite cada color (para FARO)

| Color | Asociación más citada | Riesgo | Uso en FARO |
|---|---|---|---|
| **Azul profundo** `#123A5C` | Confianza, seriedad, fiabilidad. Muy usado por bancos, aseguradoras y tecnológicas (PayPal, IBM). | Demasiado azul resulta frío y distante. | Textos principales, cabecera y resumen de ganancias: el «suelo» de confianza. |
| **Teal** `#0B6F6A` | Mezcla del azul (confianza) y el verde (calma, frescura); en diseño se asocia a creatividad y sofisticación. | Poco conocido como color de marca: hay que repetirlo para que se recuerde. | Marca, botones de confirmación, estado «en curso», el faro. |
| **Ámbar** `#F2A516` | Calidez, optimismo, energía. El naranja destaca sin la alarma del rojo y anima a actuar. | El amarillo intenso inquieta; en exceso con azul crea «ruido» visual. | **Solo** para la acción principal de cada pantalla («Neuer Auftrag», «Annehmen») y los mandados en el mapa. |
| Verde `#1B6E3A` | Éxito, terminado. | — | Solo para el estado «Abgeschlossen». |
| Rojo `#A8261D` | Alarma, error. | Usado en precios o botones normales genera ansiedad. | Solo para errores y para cancelar. |

## 3. Diferenciación en Alemania

| Servicio | Color de marca | Fuente |
|---|---|---|
| Wolt | Azul claro (mochilas) | tageskarte.io, startbase |
| Flink | Rosa (mochilas) | startbase |
| Lieferando | Naranja | Conocimiento general, sin verificar |
| DHL / Deutsche Post | Amarillo | Conocimiento general, sin verificar |
| Hermes | Naranja o azul | Conocimiento general, sin verificar |

**Consecuencias:**

- El **teal oscuro** como color principal no choca con ninguno.
- El **ámbar** se queda en acento (no como fondo grande), para que FARO no parezca DHL ni Lieferando.
- Hay que evitar el rosa (Flink) y el azul claro (Wolt) como colores dominantes.

## 4. Reglas de uso

1. **Proporción 60-30-10:** 60 % neutros (fondos gris verdoso), 30 % azul profundo y teal, 10 % ámbar. Así se evita el ruido de mezclar azul y naranja a partes iguales.
2. **Un solo botón ámbar por pantalla:** la acción principal. El resto de botones van en teal o neutros.
3. **El estado se indica con color y con texto** (chip con palabra), nunca solo con color (daltonismo).
4. **Rojo solo para errores y para cancelar.** Los precios nunca van en rojo.
5. **Ámbar como gráfico sobre fondo claro:** necesita un borde en ámbar oscuro `#B36B00`. El ámbar puro sobre blanco solo llega a 2,1:1 y la norma pide 3:1 para elementos gráficos.

## 5. Contraste (WCAG 2.2 AA)

AA pide 4,5:1 para texto normal y 3:1 para texto grande y elementos gráficos.

| Combinación | Contraste | Cumple |
|---|---|---|
| Texto `#0F2233` sobre fondo `#EEF3F3` | 14,5:1 | Sí |
| Texto secundario `#4F6273` sobre blanco | 6,3:1 | Sí |
| Blanco sobre teal `#0B6F6A` (botón) | 6,0:1 | Sí |
| Azul profundo `#123A5C` sobre blanco | 11,8:1 | Sí |
| Texto `#2B1B00` sobre ámbar `#F2A516` (botón) | 8,1:1 | Sí |
| Ámbar `#F2A516` sobre blanco (gráfico) | 2,1:1 | **No**: usar borde `#B36B00` (4,2:1) |
| Error `#A8261D` sobre blanco | 7,1:1 | Sí |
| Éxito `#1B6E3A` sobre `#DFF1E5` | 5,3:1 | Sí |
| Modo oscuro: texto `#E6EEF2` sobre `#0A1620` | 15,6:1 | Sí |
| Modo oscuro: `#04201E` sobre teal `#43B9B0` | 7,2:1 | Sí |
| Modo oscuro: ámbar `#F5B843` sobre `#112331` | 9,0:1 | Sí |

Calculado con la fórmula de luminancia relativa de WCAG.

## 6. Qué validar con usuarios (01.7)

- ¿El teal transmite «de confianza» o «frío»? Pedir 3 palabras al ver la pantalla de inicio.
- ¿Se entiende sin explicación que el botón ámbar es «lo que tengo que hacer»?
- ¿Alguien confunde FARO con un servicio de paquetería por el ámbar?
